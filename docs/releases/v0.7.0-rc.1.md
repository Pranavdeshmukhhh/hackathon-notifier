## Repairs made during the gate

- Compatible npm security updates; secure pytest/pip lock; IANA `tzdata` for
  Windows/no-system-timezone environments, reproduced failing before the fix.
- Docker ignore rules leaked five synthetic secret paths, including nested `.env`;
  all are now excluded while example files remain available.
- A non-root image could not read 0600 source copied from the workspace. Source
  read/traversal permissions are now normalized without making it non-root-owned.
  Health checks follow dynamic `PORT` and bypass proxies only for loopback probes.
- CI now enforces real runtime/critical coverage floors, dependency audits, static
  security checks, tracked-file secrets, context regressions, image/migration smoke,
  source/matching fixtures and production browser flows. Quality actions and
  fixture/scanner images are pinned; no unattended production schedule was added.
- Removed stale verification/uptime/scalability claims from current release docs;
  setup, architecture/ADRs, contributor and shipped license notices are maintained.
